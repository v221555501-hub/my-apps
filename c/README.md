# 第五版：所有行事曆統一使用 Gmail 的 Google 行事曆

側邊行事曆直接開啟 Google，各筆事項也使用同一個本機設定的 Gmail 帳號帶入 Google 行事曆。App 不再顯示自己的月曆，也不要求 OAuth ID。請在 Google 頁面登入、確認並儲存；這是手動加入，後續修改與刪除不會自動同步。

Gmail 帳號為選填，只存在輸入它的裝置，未寫進公開專案。提醒及假日顯示請在 Google 行事曆設定。開始／截止時間、資料夾、獨立修繕與會議分頁、本機保存及備份功能保留。

部署：先匯出備份，將本層檔案及 b/c 資料夾覆蓋上傳 GitHub 根目錄、Commit changes，等待 Pages 部署；保持 main / (root)。手機安裝仍為 PWA，需瀏覽器及系統確認。
